# Trustee 101 - Family Governance Framework (Lesson 9)

## Family Governance Framework — Co-Trustee Agreement 1. Decision Rights by Category

| Item | Rule |
| --- | --- |
| Distributions < $5,000 | Either trustee approves independently |
| Distributions $5k-$25k | Both trustees' written consent required |
| Distributions > $25k | Both trustees + 3-day deliberation |
| Investments | Delegated to professional advisor (recommended) |
| Tax filing / Accounting | Either trustee + CPA oversight |
| Beneficiary comms | Both trustees receive copies of all comms |
| New accounts | Both trustees' approval required |

## 2. Dispute Resolution

| Step 1 | Each trustee writes their position. Share both documents within 3 business days. |
| Step 2 | 5-day cooling-off period — no action on the disputed matter. |
| Step 3 | Facilitated discussion with trust attorney, CPA, or professional trustee. |
| Step 4 | Neutral third party issues non-binding recommendation. |
| Step 5 | If still deadlocked: remainder beneficiaries vote, or court-appointed trustee decides, or arbitration per trust terms. |
