# Quarterly Review Guide — What a Quarterly Trust Review Covers

## Overview
A quarterly review is a routine trustee meeting held every three months to review the trust's financial status, beneficiary circumstances, and administrative compliance. It ensures the trustee stays informed and documents their ongoing fiduciary diligence.

## What a Quarterly Review Covers

### 1. Financial Review
- Review trust account balances and recent transactions
- Check investment performance and asset valuations
- Verify income (interest, dividends, rent) has been received and recorded
- Review expenses paid from trust funds

### 2. Distributions & Beneficiaries
- Review any distributions made during the quarter
- Check if any beneficiaries have requested distributions or have pending needs
- Verify beneficiary contact information is current
- Confirm distribution decisions align with the trust's HEMS standard

### 3. Tax & Compliance
- Verify estimated tax payments are on track (if applicable)
- Check for any upcoming filing deadlines
- Review state compliance requirements
- Ensure any 1041 estimated payments are current

### 4. Asset & Schedule A Review
- Confirm trust assets are accounted for and properly titled
- Check if any asset valuations need updating
- Review Schedule A for any additions or disposals during the quarter

### 5. Documentation
- Document the review in meeting minutes (use the `quarterly_review` minutes template)
- Note any decisions made, actions taken, or follow-ups needed
- File minutes with trust records

## TrustOffice Workflow for Quarterly Reviews

1. **Calendar** — The quarterly review task appears in your calendar. Mark it complete after the review.
2. **Review** — Go through the checklist above using TrustOffice sections:
   - **Transactions** — review money movement
   - **Schedule A** — confirm assets
   - **Beneficiaries** — check beneficiary status
   - **Distributions** — review any quarterly distributions
3. **Minutes** — Document the review using **Minutes → Create Minutes → Quarterly Review Meeting** template (`/minutes/create?type=quarterly_review`)
4. **Calendar** — Schedule the next quarterly review (3 months out)

## Quarterly Review Checklist Template

- [ ] Reviewed trust account balances and transactions
- [ ] Checked investment performance
- [ ] Verified beneficiary information is current
- [ ] Reviewed any distributions made this quarter
- [ ] Confirmed tax filings/estimates are on track
- [ ] Updated asset valuations if needed
- [ ] Documented review in quarterly review minutes
- [ ] Scheduled next quarterly review

## When to Use
- Every 3 months as part of routine trust administration
- When the calendar suggests a quarterly review is due
- When the user asks "what do I do for my quarterly review"
